## Responsive behavior

- Below 960px the comparison stacks. List mode hides the schematic. Map mode shows it above the list.
- At 960px and above the schematic and the list sit in two columns, including in List mode.
- Text size control sets the root font to 100%, 125%, or 150%. Layout uses wrapping, not a fixed phone width, in the prototype.
- Wireframes are drawn as a phone because the PRD is a mobile concept. The wide layout is specified in the high-fidelity notes.
